# 走走台灣｜互動式旅行規劃器

一個使用 HTML、CSS、JavaScript 製作的台灣城市旅行規劃網頁。開啟 [index.html](index.html) 即可使用，不需要安裝套件或連接資料庫。

## 主題與互動功能

- 選擇台北、台中、台南或高雄。
- 選擇 1～3 天的旅行長度。
- 選擇文化、美食、自然或隨興探索偏好。
- 產生每日行程，並可重新搭配、複製文字或列印。
- 手機與電腦皆可閱讀。

## AI 協作過程

這份作業先參考了 [Vibe2026 範例](https://github.com/rkuo2000/Vibe2026) 的「提示詞 → 互動網頁 → HTML」呈現方式，再選定「互動式旅遊行程規劃器」為主題。給 AI 的需求摘要是：

> 製作一個可直接部署到 GitHub Pages 的單一 `index.html` 互動式網頁。讓使用者選擇台灣城市、旅遊天數與偏好，按下按鈕後產生行程。畫面需適合手機使用，並提供重新產生、複製與列印功能。

完成初稿後，檢查了檔案結構與城市資料，並補上旅遊資訊的提醒。行程是預先整理的景點組合，並非即時推薦；出發前仍需確認景點開放時間、交通、預約與天氣。

## 發布方式

將 `index.html` 與本檔放在 GitHub repository 根目錄。在 repository 的 **Settings → Pages** 中選擇 **Deploy from a branch**，來源設為 `main` 與 `/(root)`，儲存後即可取得 GitHub Pages 網址。
